<product_requirements>
The AM AI SAFE web app aims to provide an AI governance assessment tool. Users can sign up/login, start new assessments, answer 88 questions across 11 domains, view results, visualize a heatmap, and generate PDF reports. A dashboard helps manage incomplete and completed assessments.

**Implemented features:**
-   **Authentication:** Email/password sign-up and login, session management. User roles (Admin/Member) are conceptualized but not fully detailed in implementation.
-   **Assessment Lifecycle:** Users can start new assessments with auto-naming. Answers are saved dynamically.
-   **Question Bank:** Fixed set of 11 domains x 8 questions (88 total) are seeded into the database, including explanations and pre-defined answers (Ideal, Good, Basic, Non-Ideal, Other).
-   **Assessment Flow:** Questions are presented domain-by-domain.
-   **UI/UX:** Professional branding (teal color scheme), responsive design, a dashboard showing assessment stats, and a simplified status view displaying all questions on one screen. The Other answer option now allows text input and flags the question for review.

**Key pending refinements:**
-   Ensuring *all* content from the 'Explanation' column is displayed.
-   Ensuring *correct* content for each pre-defined answer option is displayed.
</product_requirements>
