<product_requirements>
The AM AI SAFE application is a platform for organizations to evaluate their AI maturity through specialized assessments. Initially an MVP with a single AI System Maturity Assessment, it has been expanded to support a suite of assessments, including a free AI Awareness assessment and two premium offerings: the AI Readiness Assessment and the Organisation-wide AI Maturity Assessment.

**Core Functionality:**
*   **Dynamic Assessment Engine:** The application is built on a flexible framework where the  dictates the questions, scoring logic, and UI presentation.
*   **User Onboarding:** Each assessment has a unique pre-assessment form to gather relevant metadata before the user begins.
*   **Assessment Interface:** Users are presented with questions, multiple-choice answers, and in-context help via Additional Guidance and Evidence Types tooltips.
*   **Progress & Results:** Users can view their progress on a View All page and, upon completion, will see a results summary.

**Implemented Work:**
The AI Readiness and Organisation-wide assessments have been fully built out, from parsing user-provided CSVs/markdown files for questions and tooltips to integrating them across the entire backend and frontend. This involved extensive bug fixing related to data fetching, UI rendering, and routing.
</product_requirements>

<key_technical_concepts>
- **Backend:** FastAPI (Python) with Pydantic for data modeling.
- **Database:** MongoDB for data persistence.
- **Frontend:** React.js with Tailwind CSS for styling and Axios for API communication.
- **Core Architecture:** A modular design pattern using an  string to conditionally control logic and rendering throughout the full stack. This allows for easy extension with new assessment types.
- **Authentication:** JWT-based user authentication.
</key_technical_concepts>
